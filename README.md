🏨 Eclipse Hotel – API de Gerenciamento de Reservas

Projeto desenvolvido como parte de um desafio técnico de processo seletivo, seguindo práticas profissionais, arquitetura organizada e integrações reais.

✨ Tecnologias Utilizadas
Back-end

- Java 17

- Spring Boot

- Spring Web

- Spring Data JPA

- Hibernate

- PostgreSQL

- Lombok

- Swagger / SpringDoc

- JUnit (testes unitários)

- Cache com Spring Cache + TTL de 30 segundos

Ferramentas & Workflows

- GitFlow (main, develop, feature branches)

- Postman para testes

- Hibernate auto-ddl (update)

- Tratamento global de exceções

- Validações Bean Validation

- DTOs de request/response

📘 Sobre o Desafio

O desafio consistiu em implementar um sistema completo de reservas para o Eclipse Hotel, conforme documentação oficial fornecida pela empresa 

Foram exigidas as seguintes entregas:

CRUD de Customer
CRUD de Room
CRUD parcial de Reservation com regras
Validação de conflito de datas
Máquina de estados
Endpoint de checkout
Endpoint de reservas por período
Endpoint de quartos ocupados
Adição da entidade Address integrada a Customer
Arquitetura em camadas (Controller, Service, Repository)
Logs e boas práticas

Arquivo SQL com análises pedidas pela PO
